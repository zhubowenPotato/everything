# Everything 子应用启动器

双击 **`Everything Launcher.vbs`** 即可打开图形启动器。它使用 Windows PowerShell 和 WPF，不显示控制台窗口。

也可以双击 `Start Menu.bat`，效果相同，只是命令提示符会短暂闪现后关闭。

## 界面

- 启动器和全部 51 个子应用默认使用中文界面。
- 左侧按分类筛选：办公、协作、创意、工程、效率、财务、业务、开发、游戏。
- 顶部搜索框可以搜索中文名、英文名、源码目录或功能描述。
- 每个卡片显示应用图标、中文名称、中文简介和源码目录；悬停名称可查看中英文对照。
- 点击卡片或“启动”按钮即可启动；启动后按钮变为“停止”。
- 底部可以打开日志目录，或一次停止所有正在运行的应用。
- 关闭启动器时，会停止本项目的全部本地开发服务，不需要逐个关闭。
- 每个应用会分配一个真正空闲的端口；即使 5173 已被其他服务占用，也会自动启动在 5174、5175 等新端口，不会错误打开旧应用。
- 启动器会等到端口真正开始监听后再自动打开浏览器；若浏览器没有出现，可点击“日志目录”查看日志中的 `Local:` 地址。

## 子应用中文界面

- 子应用页面的右下角有一个圆形语言按钮：显示“中”表示中文，点击可切回英文；显示“EN”时点击可恢复中文。
- 首次打开某个应用时，如果按钮显示“点击汉化”，请点击按钮或页面任意位置一次，让 Chrome / Edge 下载本地中文语言包。
- 新版 Chrome / Edge 会自动翻译动态菜单、按钮、提示和弹窗；即使浏览器不支持本地翻译，内置常用词典仍会汉化主要界面。
- 文档正文、电子表格单元格、代码编辑器、画布等用户内容不会被翻译。
- 汉化脚本位于 `dev/zh-cn-ui.js`。修改后运行 `node dev/sync-zh-cn-ui.mjs`，即可同步到全部子应用入口。

## 行为

- 首次启动某个应用时会自动执行 `npm ci`，之后会跳过安装。
- 开发服务器在后台启动，浏览器会自动打开；不再弹出黑色控制台窗口。
- 多个应用可以同时运行，Vite 会自动选择空闲端口。
- 启动日志保存在 `_logs/<应用目录>.log`，启动失败时可从底部“日志目录”查看。
- 需要 Node.js 22.12 或更高版本。

## 目录

- `Everything Launcher.vbs`：推荐的图形界面入口，无控制台窗口。
- `Start Menu.bat`：兼容入口，调用同一个图形界面。
- `_ui/launcher.ps1`：启动器界面与进程管理逻辑。
- `_ui/launcher.xaml`：界面布局和样式。
- `_lib/launch-app.bat`：单个应用的实际启动逻辑。
- `../dev/zh-cn-ui.js`：子应用共享汉化运行时。
- `../dev/sync-zh-cn-ui.mjs`：把汉化脚本同步到全部子应用入口。
- `_logs/`：运行日志，首次启动时自动创建。
- `01-Office` 到 `09-Games`：51 个应用的可双击 `.bat` 入口，仍可直接使用。

## 直接启动单个应用

进入分类目录，双击对应的 `.bat` 文件即可。这个方式会保留一个控制台窗口，方便查看 Vite 输出或按 `Ctrl+C` 停止服务。
